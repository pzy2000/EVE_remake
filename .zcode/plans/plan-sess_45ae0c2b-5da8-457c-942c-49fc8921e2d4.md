# STARFALL ODYSSEY 汉化计划（默认中文，可切换英文）

## 核心设计

自建轻量本地化系统（gettext 风格，**英文原文即键**），不引入 Unity Localization 包（避免重量级依赖和手工编辑器资产流程）。

**四条铁律：**
1. **英文为键、查不到原样返回** —— 任何漏译的字符串回退显示英文，游戏永不因缺词条而崩坏。
2. **存档/状态永远存英文**，只在显示或发射日志时翻译 —— 旧存档完全兼容，切语言不污染存档。
3. **库级默认英文、应用级默认中文**：`L10n` 静态默认 English（57 个现有测试全部断言英文字符串，保持绿灯）；`AppRoot.Awake` 从 PlayerPrefs 读 `starfall.language`（缺省 `"zh"`）→ 首次启动即中文。
4. **带参数的句子用 `{0}` 占位符**：`Tr("Docked at {0}.", station)` → zh 查到 `"已停靠于{0}。"` 后 `string.Format(InvariantCulture, ...)`；En 模式直接格式化英文键。

**语言切换**：设置面板（三个场景共有）新增「语言」行，点击在 中文/English 间切换 → `AppRoot.SetLanguage` 写 PlayerPrefs 并触发 `L10n.LanguageChanged` → 各 UI 控制器重新跑 UXML 本地化 + AppRoot 标脏快照全量重建。战斗日志历史行保持切换前语言（业界常规做法）。

## 新增文件

### 1. `Domain/L10n.cs`（纯 C#，无 Unity 依赖，Simulation/UI/App 均可访问）
```csharp
public enum L10nLanguage { English, Chinese }
public static class L10n
{
    public static L10nLanguage Language { get; }        // 默认 English
    public static bool IsChinese { get; }
    public static event Action LanguageChanged;          // 切换后触发一次
    public static void SetLanguage(L10nLanguage lang);
    public static string Tr(string key);                 // En→原样；zh→字典命中或回退原样
    public static string Tr(string key, params object[] args);
    public static string TrName(string properName);      // 专有名词音译（见第4点）
}
```

### 2. 词条数据 `Domain/L10nData/`（3 个分节文件，静态 `(string en, string zh)[]` 数组合并进字典，~500 条）
- `L10nData.Ui.cs` —— UXML 界面文本 + 控制器动态格式串 + 枚举显示值（"Frigate"→护卫舰、"Offered"→待接取、"Gas Giant"→气态巨行星、"High/Mid/Low"→高/中/低槽、"PC/Mobile"→PC/移动端）
- `L10nData.Game.cs` —— GameSession 战斗/交易/任务日志 ~68 条、任务标题描述、AppRoot 日志/列表行 ~45 条、OverviewContactBuilder 类型/详情 ~13 条、导入错误 ~12 条
- `L10nData.Content.cs` —— 势力/舰船/装备/物品名与描述 ~88 条 + **专有名词词素表**

### 3. `UI/UiLocalizer.cs`
- `Apply(VisualElement root)`：深度遍历，对所有 TextElement 的 `text` 与 `tooltip` 做翻译；原文存入元素属性包（`SetProperty`），重复调用幂等（可来回切换）；同时 `root.EnableInClassList("lang-zh", IsChinese)` 切字体。
- UXML 文件**零修改**（保留英文原文作为运行时键）；代码构建的设置面板标签同样被覆盖。

### 4. 字体 `Fonts/NotoSansSC/`（Noto Sans SC Regular + Bold，OFL 协议免费）
Orbitron/Rajdhani 无 CJK 字形，必须补中文字体。获取优先级：Google Fonts 静态 TTF 接口 → noto-cjk GitHub Release → 备选 MiSans/阿里普惠体。必须 TTF（Unity UI Toolkit 对 CFF-OTF 支持不可靠）。

## 专有名词音译（词素分段法）

`UniverseGenerator` 的名字全部由封闭词表组合（音节、姓氏、后缀、模式）。`TrName` 实现：先整串精确匹配（"Directorate Bureau"→理事会分局等固定名），否则按空格分词 + 最长匹配词素表逐段音译重组：
- 音节表 Hel→赫、ara→拉 …（系统名 "Helara"→赫拉拉）
- 人名 Aren→阿伦、Voss→沃斯（"Aren Voss"→阿伦·沃斯）
- 模式："{名} Station {n}"→"{中文名} {n}号空间站"、"Stargate to {名}"→"通往{中文名}的星门"、"{星} Belt {希腊}"→"{星}小行星带 α"、"Prime/Major/Minor"→主星/大卫星/小卫星
- 确定性、可单测（同输入同输出）。玩家自由输入的呼号原样保留。

显示点（星图行、总览天体列、代理人行等）调用 `Tr(name)` / `TrName(name)`；`GameSession` 组句时对嵌入名调用 `TrName` 再传参。

## 验证

- 新增 `L10nTests`：默认英文恒等、zh 命中/回退、格式化参数、TrName 确定性与已知映射、切换事件触发。
- 现有 51 EditMode + 11 PlayMode 测试必须全绿（库级默认 English，GameSession 输出不变）。
- 若本机装有 Unity 6000.1.10f1（查 `/Applications/Unity/Hub/Editor/`）：batchmode `-runTests` 跑 EditMode 全套做编译+回归验证。
- 最后由你在 Unity 编辑器里目检：中文渲染无豆腐块、切换即时生效、字体风格协调（必要时微调 `.lang-zh` 字号）。

## 风险与对策

- **字体获取**：网络下载失败则依次换源；最坏用可变字重 TTF 单文件（标题不加粗，仅颜色/字号区分）。
- **漏译**：英文回退兜底，中文模式下肉眼巡屏即可发现（英文残留一眼可辨）。
- **切语言后旧日志行混语**：可接受，与多数游戏一致。
